# microCMS 記事作成ガイド

## アイキャッチ画像

### 推奨サイズ
- **1200 x 630px 以上**（アスペクト比 1.91:1）
- OGP画像（SNS共有）と同じ比率なので、記事表示・SNSどちらでも綺麗に表示される
- これより小さい画像は引き伸ばされてぼやける可能性あり

### 注意点
- **重要な要素は画像の中央に配置する** — 表示箇所によってクロップされるため、端に文字やオブジェクトがあると切れる場合がある
- **形式**: PNG / JPG / WebP いずれもOK
- **ファイルサイズ**: 気にしなくてOK（microCMSが自動で最適化・WebP変換してくれる）

### 表示箇所ごとのサイズ
| 表示箇所 | サイズ | 備考 |
|----------|--------|------|
| 記事詳細のアイキャッチ | 960 x 540 | 自動クロップ |
| 記事一覧のサムネイル | 600 x 400 | 自動クロップ |
| ホーム画面 | 160 x 160 | 正方形にクロップ |
| SNS共有（OGP） | 1200 x 630 | 自動クロップ |

## コードブロック

### 言語指定
- リッチエディタのコードブロックで**言語を指定**すると、シンタックスハイライトがより正確になる
- 未指定の場合はコード内容から自動推測される

### ファイル名
- コードブロックの**ファイル名**を設定すると、コードブロックの上にファイル名ラベルが表示される

## リンクカード
- 段落にURLだけを記載すると、自動的にOGP情報付きのリンクカードに変換される
- URLの前後に他のテキストがあると通常のリンクとして表示される

## タグ
- APIスキーマのセレクトフィールドで事前に登録されたタグから選択する
- 新しいタグを追加したい場合は、microCMS管理画面の「API設定」→「APIスキーマ」からセレクトフィールドの選択肢を追加する

## 下書き・プレビュー
- microCMSで下書き保存した記事は本番サイトには表示されない
- 公開前の見た目確認は `npm run dev` でローカルプレビュー可能
